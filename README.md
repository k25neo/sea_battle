# ⚓ Морской бой

Онлайн «морской бой» на Go: сервер с комнатами + веб-интерфейс. Два игрока
создают/входят в комнату по коду и играют друг против друга по сети.

## Запуск

```bash
go build -o sea-battle .
./sea-battle -addr :8080
```

Откройте `http://localhost:8080` в двух вкладках (или на двух машинах):
в одной создайте комнату, в другой введите её код.

## Правила

Классические: поле 10×10, флот 1×4, 2×3, 3×2, 4×1, корабли нельзя ставить
вплотную (в том числе по диагонали). Попадание — стреляешь ещё раз,
промах — ход переходит противнику. Потопленный корабль автоматически
обводится «ореолом».

## Архитектура

```
main.go                 HTTP-сервер: статика web/ + WebSocket /ws
internal/game/          чистая игровая логика (поле, флот, выстрелы) + тесты
internal/room/          комнаты, игроки, состояние партии, протокол сообщений
web/                    фронтенд: index.html, style.css, app.js (чистый JS)
```

Протокол — JSON поверх WebSocket. Клиент шлёт `create` / `join` / `place` /
`fire`, сервер отвечает `room` / `opponent` / `placed` / `start` / `shot` /
`game_over` / `error` / `opponent_left`. Вся валидация (расстановка, ходы,
повторные выстрелы) — на сервере, клиенту нельзя доверять.

## Боевой сервер

Игра развёрнута на `printlab3d.ru`:

- адрес: **https://printlab3d.ru/sea/** (дубль: https://sea.printlab3d.ru — заработает после распространения DNS)
- Go-приложение: `/opt/sea-battle` (бинарник + `web/`), systemd-сервис `sea-battle`,
  слушает `127.0.0.1:8090`
- nginx: HTTPS (Let's Encrypt, certbot с nginx-аутентификатором), прокси `/sea/` → Go,
  HTTP редиректит на HTTPS; поддержка WebSocket через `Upgrade`
- приложение умеет работать и в корне, и под префиксом `/sea/` (срезает префикс само)

Обновление игры:

```bash
GOOS=linux GOARCH=amd64 go build -o sea-battle .
scp sea-battle web/* root@СЕРВЕР:/tmp/   # затем разложить по /opt/sea-battle
ssh root@СЕРВЕР 'systemctl restart sea-battle'
```

## Тесты

```bash
go test ./...
```

- `internal/game` — юнит-тесты логики;
- `internal/room` — тесты комнат и состояния партии;
- `main_e2e_test.go` — полная партия двух игроков поверх настоящего WebSocket.
